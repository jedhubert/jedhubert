### Featured projects

**AI & LLMs**

- **[LLM Inference API](https://github.com/jedhubert/LLM-Inference-API)**: containerized TinyLlama 1.1B service on FastAPI with Redis response caching (cache hits under 5 ms), one-command deploy scripts and health-check monitoring.
- **[Aria, E-Commerce Voice AI Assistant](https://github.com/jedhubert/E-Commerce-Voice-AI-Assistant)**: real-time voicebot over LiveKit WebRTC. Silero VAD → local Whisper STT → Llama 3.3 70B on Groq → Piper TTS, with tool calls for orders, products and a local RAG for policies.
- **[AI Student Digital Twin](https://github.com/jedhubert/AI-Digital-Twin-)**: predicts placement readiness, forecasts the trend, maps skill gaps and runs Gemini-powered resume analysis and mock interviews.

**ML & data**

- **[Bank Term Deposit Prediction](https://github.com/jedhubert/Bank-Term-Deposit-Subscription-Prediction)**: end-to-end pipeline comparing 7 models plus an ensemble on imbalanced data, explained with SHAP and served in Streamlit.
- **[Netflix Content Strategy Analysis](https://github.com/jedhubert/Netflix-Content-Strategy-Analysis)**: what drives hours viewed across 24,812 titles by type, language, release month, season and weekday.
- **[Market Data Scraper for ML](https://github.com/jedhubert/Scraping-Market-Data-for-ML-Pipelines)**: scrapes the most-active stocks into clean, timestamped CSVs ready for ML pipelines.

**Web apps**

- **[BloodBridge](https://github.com/jedhubert/BloodBridge)**: connects blood requesters with matching donors. Flask + MySQL, deployed on AWS EC2.
- **[Contact Keeper](https://cloud-contacts-easy.lovable.app)**: cloud phone directory in React + TypeScript with a Supabase database managed through Drizzle.
